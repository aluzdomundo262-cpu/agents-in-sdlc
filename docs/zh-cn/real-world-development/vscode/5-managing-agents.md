启用 GitHub Copilot 智能体模式后，它会自主探索代码库、提出更改、编辑文件并运行命令。由于这些操作会在你的计算机上实时执行，VS Code 中的 Copilot Chat 会持续显示每次工具调用和文件编辑。你可以直接在聊天中查看每个差异、接受或撤销单项更改，并通过后续提示引导对话，在不离开编辑器的情况下完善或扩展工作。

本练习将介绍如何：

- 实时监控无障碍智能体的工作。
- 审查并接受建议的文件编辑。
- 在会话进行时引导智能体，在高对比度模式之外添加浅色模式切换开关。

## 场景

你在[练习 4][previous-lesson]中使用的无障碍自定义智能体正在实现高对比度模式。工作期间，设计团队又提出了需求：为不喜欢默认深色主题的用户添加浅色模式切换开关。你无需从头开始新对话，而是引导当前会话扩展工作范围。

## 监控 Copilot 的进度

Copilot Chat 视图会显示智能体执行的每个步骤，包括探索的文件、运行的命令和提出的编辑。每项文件编辑都会以内联方式显示差异，并附带 **Keep** 和 **Undo** 控件。

1. 返回练习 4 中使用的 Copilot Chat 视图。
2. 智能体工作时，滚动聊天内容，查看每次工具调用。你会看到文件读取、文件编辑，以及它请求运行的终端命令。
3. 智能体提出文件编辑时，差异会以内联方式显示：
    - 选择 **Keep** 接受更改。
    - 选择 **Undo** 撤销更改，让智能体重新尝试。
4. 也可以打开聊天顶部的 **Files changed** 指示器，查看智能体在本次会话中修改的所有文件。

> [!NOTE]
> 如果工具调用需要权限（例如运行终端命令），智能体会暂停并显示 **Allow** 提示。只批准你认可的命令。

5. 等待智能体完成高对比度模式的实现。完成后应会显示更改摘要。

## 引导智能体添加浅色模式

高对比度模式完成后，继续使用同一对话添加浅色模式切换开关。由于仍处于同一聊天会话，智能体会保留先前工作的上下文，包括修改过的组件、采用的样式方案和设置的本地存储模式。

1. 在 Copilot Chat 输入框中发送以下后续提示：

    ```plaintext
    做得不错！现在请在高对比度切换开关旁添加浅色模式开关。浅色模式应采用相同模式，通过本地存储保存设置，并在同一个用户界面区域中提供。用户应能分别启用高对比度模式和浅色模式。
    ```

2. 智能体会继续处理，探索已有更改并提出浅色模式的补充内容。
3. 和高对比度模式一样，逐项审查新更改。对每个差异使用 **Keep** 或 **Undo**。
4. 如果智能体的实现方向不符合预期，例如试图以不理想的方式重构切换界面，可以选择聊天输入框旁的 **Stop** 按钮停止任务，然后发送澄清后的后续消息。

> [!TIP]
> 引导正在运行的会话比从头开始更快。可以用后续提示要求调整（“简化层叠样式表 (CSS)，改用 CSS 变量，不要重复选择器”）、纠正方向（“不要添加第三个开关，将浅色模式集成到现有设置面板”），或扩展范围（“还要为两个开关添加键盘快捷键”）。

## 审查工作集

提交更改前，快速检查智能体修改的所有文件。

1. 在 VS Code 中打开 **Source Control** 视图。
2. 审查所有已更改文件。你应会看到 Astro 组件、样式和相关测试的更新。
3. 打开几个已更改的文件并查看差异。确认其中体现了自定义智能体要求的无障碍模式，包括无障碍富互联网应用程序 (ARIA) 属性、键盘导航、语义化超文本标记语言 (HTML) 和本地存储持久化。
4. 确认满意后，在 Source Control 面板中暂存并提交更改。下一课会发布这些更改。

## 总结与后续步骤

你已使用 Copilot Chat 智能体模式监控并引导正在进行的会话：逐项审查文件编辑、接受或撤销更改，并通过后续提示扩展工作，同时保留现有上下文。

本课中，你：

- 实时监控了智能体的工作。
- 接受或撤销了单项文件编辑。
- 在会话进行时使用后续提示引导智能体。
