Esta lección es opcional y merece la pena dejarla para cuando te resulte natural el ciclo de trabajo local. El comando `/remote` mantiene la sesión en ejecución en tu equipo y, al mismo tiempo, la hace accesible desde la web y la aplicación móvil de GitHub Copilot. Debes mantener el equipo encendido mientras sigues la sesión desde otro dispositivo.

En esta lección:

- harás que una sesión en curso esté disponible de forma remota.
- seguirás la sesión desde el navegador o la aplicación móvil de GitHub Copilot.
- revisarás los cambios resultantes como los de cualquier otra solicitud de incorporación de cambios.

## Continúa una sesión de forma remota

Los siguientes pasos hacen que una sesión en curso esté disponible en otro dispositivo y te permiten revisarla desde allí:

1. Abre una sesión que tenga trabajo en curso.
2. Ejecuta `/remote` para que esa sesión esté disponible de forma remota.
3. Abre en el navegador el enlace que devuelve o accede a la sesión desde la aplicación móvil de GitHub Copilot.
4. Sigue su progreso desde allí y revisa los cambios exactamente como lo harías con cualquier otra solicitud de incorporación de cambios.

> [!NOTE]
> **Esto no es delegación**
>
> La sesión sigue ejecutándose en tu equipo. No estás entregando la tarea a otro agente ni trasladándola a la nube.

## Resumen y pasos siguientes

- Has hecho que una sesión en curso esté disponible de forma remota.
- Has seguido la sesión desde el navegador o la aplicación móvil de GitHub Copilot.
- Has revisado los cambios como en cualquier otra solicitud de incorporación de cambios.
